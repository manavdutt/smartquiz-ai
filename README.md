# StudySuite AI — Free AI Quiz Generator & Study Planner

StudySuite AI is an intelligent web application designed to help students generate instant quizzes and organize their study routines using AI.

## 🚀 Key Features
- **AI Quiz Generation:** Automatically creates MCQs and practice tests based on custom topics.
- **Smart Study Planner:** Helps schedule and manage study goals effectively.
- **Interactive UI:** Clean, responsive, and student-friendly dashboard.

## 🛠️ Tech Stack
- **Backend:** Python, Django
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap/Tailwind
- **Database:** SQLite / PostgreSQL
- **Tools & Deployment:** Git, GitHub, PyCharm
